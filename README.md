# Redo Present

Skill для создания презентаций: пять композиций каждого слайда → выбор в браузере → сборка выбранных вариантов.

## Установка в Codex

Отправьте в чат Codex:

> Используй $skill-installer и установи skill по ссылке https://github.com/aljnekrasov/redo-present/tree/main/skills/redo-present

После установки, если skill ещё не появился в списке, перезапустите Codex. Устанавливать нужно всю папку `skills/redo-present`, а не один SKILL.md. Для закрытого репозитория нужен доступ к нему.

## Использование

> Используй $redo-present. Подготовь презентацию по приложенным материалам, в стиле моего брендбука. Создай пять вариантов каждого слайда и открой страницу выбора. Итоговый формат — HTML.

Приложите содержание презентации, брендбук, нужные шрифты и изображения либо укажите папку библиотеки клиента. В поставку входит обезличенная библиотека из 53 HTML-макетов: Helvetica, чёрный, белый, синий и волны. Цвета, шрифт и узор заменяются через `theme.css`. Тексты и показатели — заглушки; во всех фотоблоках используется заменяемое изображение синей ткани. Материалы конкретных клиентов не входят в поставку.

В просмотрщике подтвердите дизайн каждого слайда и отправьте обратно список вроде `2,5,1` или скачанный файл выбора. Агент соберёт именно выбранные варианты, не рисуя их заново.

## Что входит

- Инструкции процесса — `skills/redo-present/SKILL.md`.
- Нейтральная библиотека и каталог — `skills/redo-present/assets/templates/neutral/index.html`.
- Отдельная инструкция стилизации под клиента — `skills/redo-present/assets/templates/neutral/client-styling.md`.
- Инструкция адаптации — `skills/redo-present/assets/templates/neutral/instructions.md`.
- Постоянный просмотрщик — `skills/redo-present/assets/viewer/`.
- Проверка содержимого, версии и сборка — `skills/redo-present/scripts/studio.py`.
- Формат данных и команды — `skills/redo-present/references/format.md`.

Нужны Python 3.9+ и браузер. Сборщик использует только стандартную библиотеку Python. ИИ создаёт содержимое и варианты; обычный код сохраняет выбор и собирает файлы. Просмотрщик работает локально, без аналитики и внешних CDN.

Автоматическая сборка выдаёт HTML. Для Figma или PowerPoint агенту понадобятся соответствующие подключённые инструменты; они не устанавливаются вместе со skill.
